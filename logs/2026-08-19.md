- **Method used for the fringe-count comparison, step by step** (ad hoc
  script, reproduced here for the record -- not saved as a file):
  1. Load the raw JSON, pull out `Ch1 [mW]` .. `Ch4 [mW]` as 4 arrays of
     1,000,000 float samples each (`np.asarray(e['Ch{k} [mW]'], float)`).
  2. `np.median()` of each raw channel -> the weak/strong split
     (Ch1≈0.0010, Ch2≈0.318, Ch3≈0.0009, Ch4≈0.342 mW).
  3. For a **single channel** candidate: remove the slow power/DC drift by
     subtracting a moving average (`uniform_filter1d(x, n//32)`) from the
     raw channel, leaving just the AC fringe. This has to happen before
     step 4, otherwise the DC level swamps the phase.
     For a **channel-pair** candidate: instead use the existing
     `balanced(a, b)` function already in both scripts -- segment-wise
     `g = median(a_segment)/median(b_segment)`, smoothed, then
     `P = a - g(t)*b`.
  4. Build the analytic signal of that AC signal via a Hilbert transform
     done manually with FFTs (same `analytic()` helper already in both
     scripts): FFT the signal, zero out the negative-frequency half,
     double the positive-frequency half, inverse-FFT. The result is a
     complex signal whose instantaneous phase is the interference phase.
  5. `phi = np.unwrap(np.angle(analytic_signal))` -- turns the phase from
     a sawtooth in [-pi, pi] into a continuous, ever-increasing (or
     decreasing) curve by adding/subtracting 2*pi at each wrap.
  6. If `phi` runs downward overall (`phi[-1] < phi[0]`), flip its sign --
     this just fixes the sign convention (optical frequency nu decreases
     as wavelength increases), it doesn't change the physics.
  7. **Fringe count** = `(phi[-1] - phi[0]) / (2*pi)` -- literally "how
     many full interference cycles happened over the whole sweep."
  8. **Backward-step fraction** = fraction of `np.diff(phi)` that are
     `<= 0` -- every point where the unwrapped phase momentarily goes
     backward is a moment the laser's instantaneous optical frequency
     ran backward (or the phase extraction lost track, e.g. from a
     contrast dropout). This is exactly what
     `check_aux_interferometer.py`'s monotonicity check (section 2 of its
     output) already computes for whichever pair you point it at.
  9. **Calibration (dL)**: using the known laser sweep 1520->1570 nm,
     convert to a frequency span via `c/lambda` (6.03 THz used, after
     accounting for the 2% trim at each edge), then
     `tau = fringes / frequency_span`, then `dL = c * tau / n_g`
     (n_g = 1.468 for SMF-28) -- the same formula
     `check_aux_interferometer.py` prints under "3) CALIBRATION".
  10. Ran steps 3-9 for every single channel (Ch1..Ch4 alone) and for the
      pairs (1,2), (3,4), (1,3), (2,4), (1,4), (3,2), and compared the
      resulting fringe counts, backward fractions, and dL side by side.
  Full one-off script used:
  ```python
  import json, numpy as np
  from scipy.ndimage import uniform_filter1d

  with open('raw_data/2026-08-19_1miodatapoints.json') as f:
      e = json.load(f)['data'][0]
  ch = {k: np.asarray(e[f'Ch{k} [mW]'], float) for k in (1, 2, 3, 4)}

  def analytic(x):
      n = len(x); X = np.fft.fft(x)
      X[n // 2 + 1:] = 0; X[1:n // 2] *= 2
      return np.fft.ifft(X)

  def balanced(a, b, nseg=32):
      n = len(a); seg = max(n // nseg, 256); g = np.empty(n)
      for i in range(0, n, seg):
          s = slice(i, min(i + seg, n))
          m = np.median(b[s])
          g[s] = np.median(a[s]) / m if m > 0 else 1.0
      return a - uniform_filter1d(g, seg) * b

  def single(a, nseg=32):
      n = len(a); seg = max(n // nseg, 256)
      return a - uniform_filter1d(a, seg)

  def stats(name, sig, trim=0.02):
      n = len(sig); k = max(1, int(trim * n)); sl = slice(k, n - k)
      an = analytic(sig); phi = np.unwrap(np.angle(an))[sl]
      if phi[-1] < phi[0]:
          phi = -phi
      dphi = np.diff(phi)
      frac_back = float((dphi <= 0).mean())
      fringes = (phi[-1] - phi[0]) / (2 * np.pi)
      print(f'{name}: fringes={fringes:,.0f}  backfrac={frac_back*100:.3f}%  '
            f'pts/fringe={len(phi)/fringes:.2f}')

  for k in (1, 2, 3, 4):
      stats(f'single Ch{k}', single(ch[k]))
  stats('balanced Ch1,Ch2', balanced(ch[1], ch[2]))
  stats('balanced Ch3,Ch4', balanced(ch[3], ch[4]))
  stats('balanced Ch1,Ch3', balanced(ch[1], ch[3]))
  stats('balanced Ch2,Ch4', balanced(ch[2], ch[4]))
  stats('balanced Ch1,Ch4', balanced(ch[1], ch[4]))
  stats('balanced Ch3,Ch2', balanced(ch[3], ch[2]))
  ```

- Why "the fringes look great when I zoom in" (Carolina's screenshots) does
  not contradict the monotonicity failure: monotonicity is a per-sample
  direction check (is phase(sample i+1) > phase(sample i)), not something
  visible by eye in a plot of raw power -- a laser that is cruising forward
  smoothly 99.98% of the time and only reverses for a few adjacent samples
  in isolated bursts produces fringes that look completely normal to the
  eye (like a car's speedometer glitching to a small negative reading for
  a split second on an otherwise smooth highway drive -- nothing feels
  wrong from inside the car). Both of Carolina's zoomed screenshots
  (~1532.8 nm on Ch1/Ch3, ~1535.7 nm on Ch2/Ch4) happen to sit just past
  the bad zone (1520-1528 nm per the histogram above), which is why they
  look clean -- consistent with, not contradicting, the finding.
