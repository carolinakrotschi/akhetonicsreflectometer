- **`tools/identify_chip_scan.py` auf Ein-Befehl-Betrieb umgestellt.**
  `--out` ist jetzt optional: ohne Angabe wird der Ausgabeordner
  automatisch zu `results/<Datum>/<Scanname>`, wobei das Datum aus dem
  Dateinamen kommt (Praefix `YYYY-MM-DD`), sonst das heutige. `--from-csv`
  entfaellt, CSV wird an der Endung erkannt. Ein Aufruf erzeugt damit
  vier Dateien im richtigen Ordner:

      python tools/identify_chip_scan.py raw_data/2026-09-11-12-16hhi1fiber4.json --channel b27

  -> `results/2026-09-11/2026-09-11-12-16hhi1fiber4_{reflectogram.csv,
  reflectogram.png,identified.csv,identified.png}`.
