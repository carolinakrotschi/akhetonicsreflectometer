## Commands / actions (chronological)

1. Rebuilt the "MZI peak + sweep error" diagnostic plot for `scan_s1new.json`,
   since the original script could no longer be found. Assembled a new
   script, `ofdr_realdata_diagnosis.py`, from existing functions in
   `ofdr_process.py`/`ofdr_diagnose.py`.
   - `python ofdr_realdata_diagnosis.py scan_s0.json --out scan_s0_check`
     (validation run — revealed phase-unwrap jump artifacts, a data-quality
     issue specific to s0)
   - `python ofdr_realdata_diagnosis.py scan_s1new.json`
     -> clean result: main peak 46.37 mm -> 9.27 cm imbalance,
        tuning error ~= 77 pm p-p.

2. Clarified why s0/s1/s1new all look the same at the 46.4mm peak despite
   different test-fiber conditions -> the 46.4mm peak is a fixed
   reference/calibration peak ("Check 2" in the procedure), independent of
   the DUT. The actual DUT signal lives in the 6-32cm "dirt band" (a folded
   reflection, since the Nyquist range is only 0.42 m in the old 1-pm
   trigger mode).

3. Ran `ofdr_diagnose.py compare` across several scan pairs to quantify the
   6-32cm band:
   - s0 vs s1, s0 vs s1new, s1 vs s1new
   - s0 vs Terminator1, Terminator1 vs Terminator2, s0 vs Terminator2
   -> Finding: Terminator 1, Terminator 2, and the 10dB coupler all sit at
      approx. -52 to -54 dB, essentially identical to the open end (s0,
      -52.6 dB). Only "no test fiber" (s1new) is noticeably lower
      (-68.8 dB). -> None of the terminators effectively suppresses the
      reflection.

4. Built the comparison plot `band_6_32cm_comparison.png` (updated several
   times: first s0/s1/s1new, then +Terminator1/2, then +10dB coupler, s1
   removed again).

5. Discussed termination vs. gain: conclusion was that this is not an
   SNR/gain problem, since the terminator scans are just as loud as the open
   end (not quieter, as expected). Next test to narrow down the cause: a
   short patchcord (<35cm), to distinguish between Rayleigh backscatter
   along the fiber and a bad near-end connector.

6. Checked the 10dB coupler's absolute power level (Ch1/Ch2 median mW) —
   no visible ~10dB loss in the raw signal compared to the other scans. Open
   question: which port of the coupler was actually measured, same
   measurement range?

7. Reorganized the directory: created `raw_data/`, `results/2026-08-18/`,
   `george/`, `logs/`, and `CLAUDE.md` with project rules (this log is part
   of that).

8. Restructured all Python scripts and markdown docs into `tools/`,
   `legacy/`, `docs/` with clearer English names, and translated all
   German content (docs, code comments/docstrings/plot text) to English.
